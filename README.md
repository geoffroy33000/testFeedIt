# Vite + React + Redux Toolkit + RTK Query

Test front-end :

- Mini application permettant d'afficher les classements du site chess.com pour différentes cadences de jeu.
- L'objectif du test est de compléter le projet existant.
- Durée à titre indicatif : 2heures, si vous estimez devoir dépasser ce temps pour finaliser le projet, ce n'est pas bloquant.
- Le but est de comprendre votre façon de penser et d'évaluer votre niveau pour déterminer votre niveau de départ.
- Merci de limiter au maximum l'utilisation de l'IA.

## Démarrage

```bash
npm install
npm run dev
```

### CONSIGNES

1. Prendre connaissance de l'architecture existante du projet.
2. La restructurer si besoin.
3. N'afficher que les classements correspondant aux cadences définies dans le reducer "timeControls".
4. Connecter le Carrousel au reducer "timeControls" et créer une action pour chaque bouton ("<" et ">") afin de le piloter.
5. Ajouter un sélecteur permettant d'afficher soit le carrousel, soit la liste.
6. Mettre en valeur, dans le tableau, la cadence sélectionnée.
7. Mettre en forme la page afin d'obtenir une UX/UI claire et cohérente.

- Effectuer des commits réguliers et explicites, permettant de comprendre la logique et les étapes de votre développement.
